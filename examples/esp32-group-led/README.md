# ESP32 그룹 LED

ESP32 두 대가 #lab 그룹을 공유합니다. 앱의 2구 스위치 하나가 각 보드의 LED를 제어합니다. 그룹 기준 예제입니다.

## 준비물

- 보드: ESP32 개발 보드 (2대)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면
- 연동: 두 번째 ESP32: 같은 펌웨어에서 보드 설정 index=1로 s2를 읽습니다

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO4 | 330Ω 저항을 거쳐 LED 양극 | LED 음극은 GND. 두 보드 모두 |

## 사용 순서

1. Wi-Fi는 업로드한 뒤 USB로 연결해 https://test.iosignal.net/wifi/ (보드 설정)에서 넣습니다(데스크톱 Chrome·Edge, 보드가 저장). 같은 페이지에서 다른 IOSignal 서버(호스트:포트)와 장치 키도 넣을 수 있습니다. 스케치의 Wi-Fi 값에 실제 값을 쓰면 그 값이 부팅할 때마다 우선합니다. 두 번째 보드는 설정 항목 index를 1로 바꿉니다(첫 보드는 0). 같은 펌웨어를 두 보드에 씁니다.
2. 두 보드에 같은 스케치를 올립니다. 둘째 보드만 보드 설정에서 index를 1로 바꿉니다(재시작 없이 바로 적용).
3. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
4. ESP32 LEDs 카드의 스위치를 누릅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#lab$state` | `구독` | 공유 상태를 구독합니다. 보관된 값이 있으면 바로 받습니다. |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `#lab$info` | `n=ESP32 LEDs;g=HOME;t=switch2.1` | 그룹 정보입니다. 서버에 보관됩니다. g는 앱이 장치를 묶어 보여 주는 그룹이며 보드 설정 group으로 바꿉니다(바꾸면 바로 다시 보냄). |
| 장치 | 앱 | `#notify` | `#lab` | 그룹은 CID 대신 채널 이름으로 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 그룹을 찾습니다. |
| 장치 | 앱 | `#notify` | `#lab` | 구성원마다 답하고 앱은 하나로 합칩니다. |
| 앱 | 장치 | `#lab$state` | `s1=1;s2=0` | 앱이 전체 문자열을 다시 씁니다. 구성원은 자기 키를 읽습니다. |

## 참고

- 첫 보드는 s1, 둘째 보드는 s2를 읽습니다.
- 접속할 때 공유 상태를 덮어쓰지 않습니다.

## 컴파일

```sh
arduino-cli compile --fqbn esp32:esp32:esp32 examples/esp32-group-led
```
