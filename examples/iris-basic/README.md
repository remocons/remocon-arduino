# iris 기본

iris 보드의 내장 RGB LED 4개를 4구 스위치로 켜고 끕니다. 웹앱에서 하나씩, 내장 버튼 2개로 전체 또는 차례로 제어합니다. DIP 스위치와 그룹은 쓰지 않습니다.

## 준비물

- 보드: iris 보드 (ESP32-C3)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO4 | WS2812 4개 | 보드에 내장 |
| GPIO1 | 버튼 1: 전체 켜기/끄기 | 내부 풀업 |
| GPIO2 | 버튼 2: 켜진 LED를 하나씩 늘림, 4개 다음은 모두 끔 | 내부 풀업 |

## 사용 순서

1. 스케치의 WiFi 이름과 비밀번호를 실제 값으로 바꿉니다.
2. 스케치를 업로드합니다.
3. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
4. Iris Basic 카드의 스위치와 보드 버튼을 눌러 봅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `@$info` | `n=Iris Basic;t=switch4.1` | 이름과 공식 4구 스위치 타입입니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$state` | `s1=0;s2=0;s3=0;s4=0` | 현재 상태입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 접속했음을 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 장치를 찾습니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. |
| 앱 | 장치 | `<cid>@` | `s2=1` | 스위치 하나를 켜고 끕니다. 장치가 받는 태그는 @입니다. |
| 장치 | 앱 | `@$state` | `s1=0;s2=1;s3=0;s4=0` | 명령과 보드 버튼 뒤에 전체 상태를 보냅니다. 알 수 없는 명령에도 보냅니다. |

## 참고

- iris-group에서 DIP 스위치, 그룹 채널, 상태 LED를 뺀 단독 장치판입니다.
- 재접속하면 보드에 남은 상태를 다시 보냅니다.
- 시리얼 로그는 115200입니다. 보드 USB로 보려면 USB CDC On Boot를 Enabled로 컴파일합니다(fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc).
- Wi-Fi 절전을 끄고(WiFi.setSleep(false)) TCP 지연 전송을 끕니다(setNoDelay). 절전이 켜져 있으면 받는 신호가 100~800ms 늦어집니다. 2026-11-09 측정: 명령에서 상태까지 213ms → 23ms.
- Wi-Fi 송신 출력을 8.5dBm으로 낮춥니다. 한 iris 보드가 최대 출력에서 보내는 패킷을 잃어 TCP가 멈췄고(명령 60개 중 32개 응답), 낮추자 60개 모두 응답했습니다(2026-11-09).

## 컴파일

```sh
arduino-cli compile --fqbn esp32:esp32:esp32c3 examples/iris-basic
```
