# ESP-01 릴레이와 버튼

ESP-01로 릴레이와 LED를 2구 스위치로 제어합니다. 버튼으로도 릴레이를 켜고 끕니다.

## 준비물

- 보드: ESP-01 (ESP8266)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO0 | 릴레이 입력 | 부팅 시 HIGH여야 합니다 |
| GPIO1 (TX) | LED | active low. 시리얼과 함께 쓸 수 없습니다 |
| GPIO2 | 푸시 버튼, 다른 쪽은 GND | 부팅 시 HIGH여야 합니다 |

## 사용 순서

1. 스케치의 WiFi 이름과 비밀번호를 실제 값으로 바꿉니다.
2. 업로드 어댑터로 스케치를 올립니다.
3. 릴레이와 버튼을 연결하고 전원을 다시 넣습니다.
4. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
5. ESP01-Relay-Btn 카드의 1번(릴레이), 2번(LED) 스위치를 누릅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `@$info` | `name=ESP01-Relay-Btn;group=HOME;type=remocon/switch2/v1` | 이름, 분류, 화면 타입입니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$state` | `s1=1;s2=0` | 현재 상태입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 접속했음을 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 시작할 때, 1초 뒤, 이후 15초마다 보냅니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. |
| 앱 | 서버 | `<cid>@$info, $state` | `구독` | 보관된 정보와 상태를 바로 받아 카드를 만듭니다. |
| 앱 | 장치 | `<cid>@` | `s1=0` | 앱의 스위치가 값을 지정하는 명령을 보냅니다. 장치가 받는 태그는 @입니다. |
| 장치 | 앱 | `@$state` | `s1=0;s2=0` | 명령을 처리한 뒤 상태를 보냅니다. 앱의 대기 표시가 풀립니다. |
| 서버 | 앱 | `<cid>@$state` | `close` | 장치가 끊기면 서버가 보내고 카드가 사라집니다. |

## 참고

- GPIO0과 GPIO2를 LOW로 누른 채 전원을 넣으면 부팅되지 않습니다.
- GPIO1을 LED로 써서 시리얼 출력을 쓸 수 없습니다.
- s1은 릴레이, s2는 LED입니다. LED는 active low라 값을 반전합니다. 릴레이는 HIGH를 켜짐으로 두었으므로 모듈 극성을 확인해야 합니다.
