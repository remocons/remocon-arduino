# iris 그룹 조명

iris 조명 보드 여러 대가 8구 스위치 상태를 공유합니다. DIP 스위치로 그룹과 장치 번호를 정하고, 버튼과 웹앱으로 WS2812를 켭니다.

## 준비물

- 보드: iris 보드 (ESP32-C3)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면
- 연동: 같은 그룹의 iris 최대 8대: #Iris-g<번호> 상태를 공유합니다

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO4 | WS2812 4개 | 보드에 내장 |
| GPIO8 | 상태 LED | active low |
| GPIO1 | 버튼 1: 전체 켜기/끄기 | 내부 풀업 |
| GPIO2 | 버튼 2: 자기 조명 토글 | 내부 풀업 |
| GPIO21, 20, 10 | DIP 스위치: 그룹 번호 | LOW가 1, 부팅 때 읽습니다 |
| GPIO7, 6, 5 | DIP 스위치: 장치 번호 | LOW가 1, 부팅 때 읽습니다 |

## 사용 순서

1. 스케치의 WiFi 이름과 비밀번호를 실제 값으로 바꿉니다.
2. DIP 스위치로 그룹과 장치 번호를 정합니다.
3. 스케치를 업로드합니다.
4. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
5. Iris Lights 카드의 스위치와 보드 버튼을 눌러 봅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#Iris-g0$state` | `구독` | 공유 상태를 구독합니다. 보관된 값이 있으면 바로 받습니다. |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `#Iris-g0$info` | `name=Iris Lights <그룹 번호>;type=remocon/switch8/v1` | 그룹 정보입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `#Iris-g0` | 그룹은 CID 대신 채널 이름으로 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 그룹을 찾습니다. |
| 장치 | 앱 | `#notify` | `#Iris-g0` | 구성원마다 답하고 앱은 하나로 합칩니다. |
| 앱 | 장치 | `#Iris-g0$state` | `s1=1;s2=0;...;s8=0` | 앱이 전체 문자열을 다시 씁니다. 구성원은 자기 키를 읽습니다. |
| 장치 | 앱 | `#Iris-g0$state` | `s1=1;...;s8=1` | 보드 버튼은 전체 상태를 다시 씁니다. |

## 참고

- 보드 버튼은 앱처럼 공유 상태를 씁니다. 그룹 규칙의 예외입니다.
- 버튼은 보관된 상태를 받은 뒤, 또는 보관 값이 없을 때를 대비해 접속 2초 뒤부터 동작합니다.
- Wi-Fi 송신 출력을 8.5dBm으로 낮춥니다. 한 iris 보드가 최대 출력에서 보내는 패킷을 잃어 TCP가 멈췄고(명령 60개 중 32개 응답), 낮추자 60개 모두 응답했습니다(2026-11-09).
