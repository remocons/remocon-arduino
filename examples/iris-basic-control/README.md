# iris 기본 컨트롤러

iris 보드 한 대가 웹앱처럼 iris-basic 보드를 찾아 제어합니다. 상대 상태를 자기 LED 4개에 그대로 보여 주고, 내장 버튼 2개로 명령을 보냅니다.

## 준비물

- 보드: iris 보드 (ESP32-C3)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: 없음. 같은 네트워크의 iris-basic 보드를 제어합니다. 웹앱으로 동시에 제어해도 됩니다
- 연동: iris-basic 보드: 제어 대상. @$info의 name이 Iris Basic인 첫 장치를 고릅니다

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO4 | WS2812 4개 | 보드에 내장. 대상의 상태를 보여 줍니다 |
| GPIO8 | 상태 LED | active low. 대상을 찾으면 켜집니다 |
| GPIO1 | 버튼 1: 대상 전체 켜기/끄기 | 내부 풀업 |
| GPIO2 | 버튼 2: 대상의 켜진 LED를 하나씩 늘림, 4개 다음은 모두 끔 | 내부 풀업 |

## 사용 순서

1. 보드 한 대에 iris-basic을 업로드합니다.
2. 다른 보드에 이 스케치를 업로드하고, 두 보드 모두 같은 공유기의 Wi-Fi를 USB로 https://test.iosignal.net/wifi/ 에서 넣습니다(또는 스케치의 Wi-Fi 값).
3. 컨트롤러의 상태 LED가 켜지면 대상을 찾은 것입니다.
4. 컨트롤러 버튼을 누르면 두 보드의 LED가 함께 바뀝니다. 대상 보드 버튼이나 웹앱으로 바꿔도 컨트롤러에 반영됩니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 컨트롤러 | 서버 | `#notify` | `구독` | 장치들의 CID 응답을 받습니다. |
| 컨트롤러 | 장치 | `#search` |  | 접속할 때, 그리고 대상이 없으면 15초마다 보냅니다. |
| 장치 | 컨트롤러 | `#notify` | `<cid>` | 검색에 답한 장치마다 받습니다. |
| 컨트롤러 | 서버 | `<cid>@$info` | `구독` | 보관된 정보를 바로 받아 n=Iris Basic(예전 보드는 name=Iris Basic) 항목이 있는지 본 뒤 구독을 취소합니다(unsubscribe). |
| 컨트롤러 | 서버 | `<cid>@$state` | `구독` | 대상을 고른 뒤 상태를 구독합니다. 보관된 상태를 바로 받습니다. |
| 컨트롤러 | 장치 | `<cid>@` | `s1=1` | 버튼을 누르면 바뀌어야 할 LED마다 명령을 하나씩 보냅니다. |
| 장치 | 컨트롤러 | `<cid>@$state` | `s1=1;s2=0;s3=0;s4=0` | 컨트롤러 LED는 이 값으로만 바뀝니다. |
| 서버 | 컨트롤러 | `<cid>@$state` | `close` | 대상이 끊기면 상태 LED를 끄고 다시 검색합니다. |

## 참고

- 컨트롤러는 장치로 자신을 알리지 않습니다. 웹앱과 같은 쪽 역할입니다.
- 버튼은 대상의 상태를 받은 뒤부터 동작합니다.
- Iris Basic이 여러 대면 먼저 답한 한 대만 제어합니다.
- 시리얼 로그는 115200입니다. 보드 USB로 보려면 USB CDC On Boot를 Enabled로 컴파일합니다(fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc).
- Wi-Fi 절전을 끄고(WiFi.setSleep(false)) TCP 지연 전송을 끕니다(setNoDelay). 절전이 켜져 있으면 받는 신호가 100~800ms 늦어집니다. 2026-11-09 측정: 명령에서 상태까지 213ms → 23ms.
- IOSignal 9.6.0 이상이 필요합니다(unsubscribe()를 씁니다).
- Wi-Fi 송신 출력을 8.5dBm으로 낮춥니다. 한 iris 보드가 최대 출력에서 보내는 패킷을 잃어 TCP가 멈췄고(명령 60개 중 32개 응답), 낮추자 60개 모두 응답했습니다(2026-11-09).

## 컴파일

```sh
arduino-cli compile --fqbn esp32:esp32:esp32c3 examples/iris-basic-control
```
