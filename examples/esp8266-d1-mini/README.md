# D1 mini LED와 버튼

ESP8266 D1 mini의 내장 LED를 웹앱과 버튼으로 켜고 끕니다. 일반 장치의 기본 형태를 보여 줍니다.

## 준비물

- 보드: ESP8266 D1 mini
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO14 (D5) | 푸시 버튼, 다른 쪽은 GND | 내부 풀업 |
| GPIO2 (D4) | 내장 LED | active low, 배선 불필요 |

## 사용 순서

1. 스케치의 WiFi 이름과 비밀번호를 실제 값으로 바꿉니다.
2. 스케치를 업로드합니다.
3. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
4. D1-mini 카드의 버튼을 누르고 D5 버튼도 눌러 봅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `@$info` | `name=D1-mini;group=HOME;type=remocon/light/v1` | 이름, 분류, 화면 타입입니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$state` | `on=0` | 현재 상태입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 접속했음을 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 시작할 때, 1초 뒤, 이후 15초마다 보냅니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. |
| 앱 | 서버 | `<cid>@$info, $state` | `구독` | 보관된 정보와 상태를 바로 받아 카드를 만듭니다. |
| 앱 | 장치 | `<cid>@` | `toggle` | 버튼을 누르면 이름 그대로 명령이 갑니다. 장치가 받는 태그는 @입니다. |
| 장치 | 앱 | `@$state` | `on=1` | 명령을 처리한 뒤 상태를 보냅니다. 앱의 대기 표시가 풀립니다. |
| 서버 | 앱 | `<cid>@$state` | `close` | 장치가 끊기면 서버가 보내고 카드가 사라집니다. |

## 참고

- 내장 LED는 LOW일 때 켜지므로 상태 값과 핀 값이 반대입니다.

## 컴파일

```sh
arduino-cli compile --fqbn esp8266:esp8266:d1_mini examples/esp8266-d1-mini
```
